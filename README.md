
# 🔐 Password Strength Checker

A responsive web application that evaluates password characteristics
and provides feedback to help users create stronger passwords.

## Features

- Real-time password strength feedback
- Weak, Fair, Good, and Strong indicators
- Password visibility toggle
- Checks for length, uppercase, lowercase, numbers, and symbols
- Suggestions for improving password quality
- Responsive dark-mode interface
- Passwords are checked locally in the browser

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Enter a password and view the feedback.

No external libraries or server are required.

## Privacy

The application does not intentionally transmit or store the password.
Password checks are performed locally in the browser.

## Limitations

This project uses a simple educational scoring heuristic. It is not
a definitive measure of password security and does not replace
a password manager or established password-strength estimator.
